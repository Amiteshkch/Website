# Amitesh K. Chaudhary — Research Portfolio Website

This is the production-ready version of the website. Upload all files in this folder to the root of your GitHub repository.

## Files

- `index.html` — main webpage with embedded CSS and content.
- `spray-animation.js` — Three.js hero spray animation.
- `scroll-animations.js` — GSAP + Lenis smooth scrolling and section reveal animations.
- `section-animations.js` — canvas animations for research sections.
- `uploads/PD_Amitesh_PhD.pdf` — downloadable CV.
- `assets/` — optional folder for your real research images later.
- `dev/tweaks-panel.jsx` — optional development-only tweak panel. It is not loaded by the public site.

## GitHub Pages

1. Put these files in the root of your repository.
2. Commit and push to GitHub.
3. Go to Settings → Pages.
4. Set source to the `main` branch and folder to `/root`.

## Notes

The public version removes React/Babel tweak-panel loading for better performance. The animation libraries still load from CDNs, so an internet connection is required when viewing the site.
